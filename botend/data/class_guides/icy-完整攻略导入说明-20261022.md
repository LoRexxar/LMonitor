交付文件为 `icy-full-initial-20261022.zip`。包含 13 个职业、40 个专精、400 个原文章节，每个专精独立成文，版本为来源页面标注的 `12.1.5`。正文为完整章节翻译，包含专精概览、练级、快速入门、天赋与构筑、技能循环与冷却、装备选择、属性优先级、附魔与消耗品、大秘境、宏与插件。

## 导入

将 ZIP 上传到服务器，在项目根目录使用服务器现有的 Python 环境和 Django 配置执行。无需线上再次抓取或调用翻译服务。

先校验，校验操作不写入数据库：

```console
python manage.py import_class_guide_drafts --input-zip botend/data/class_guides/icy-full-initial-20261022.zip --dry-run
```

再执行导入：

```console
python manage.py import_class_guide_drafts --input-zip botend/data/class_guides/icy-full-initial-20261022.zip
```

必须明确指定 `--input-zip`；省略时，现有命令会导入默认的 Maxroll 包。

完整包会逐篇解析正文，预校验和导入可能持续数分钟，结束时输出汇总。

每篇文章的标识以 `icy-` 开头，绑定独立的专精编号。初始化标签为 `icy`、`12.1.5`、`通用`、`团本`、`大秘境`、`练级`，首次导入默认可见。与既有 Maxroll 攻略并存，不修改其正文。

重复导入相同包会跳过已导入内容。沿用当前导入器的保护规则：已有人工正文不会覆盖，已有文章的标签和可见性保留，术语冲突保留目标环境的名称。如果此前导入过早期导读包，正文可以升级，既有标签仍需按需要在管理页调整。

## 引用中文显示

正文使用现有引用格式。本次在 `botend/services/class_guide_content.py` 增加了一处显示兜底：权威中文名称缺失时，显示随文章保存的 `source_name_zh`；权威名称始终优先，兜底译名不标记为权威解析成功。

线上应同时包含该处代码改动。否则，目标环境尚无对应中文名称的引用会继续显示“待校订的技能/物品 ID”，即使中文译名已经存在于导入数据中。不需要数据库迁移或在服务器部署采集脚本。

该改动单独保存在 `icy-引用中文显示修正-20261022.patch` 中，便于核对和同步。

术语包只纳入已有可信词条和按明确编号核验的中文名称，不把机器译名写入权威词库。新增名称优先检查本地 Wago 快照；缺口按 Icy Veins 的明确编号核验 Wowhead 中文名称，仅保存名称、图标与证据地址。

## 包内数据

- `manifest.json`：40 篇文章清单、版本、标签和校验值。
- `terms.json`：导入器使用的可信中文名称。
- 每篇 `.json`：可直接导入的完整文章、原文、来源信息和组件引用。
- 每篇 `.md`：带来源和原作者信息的完整中文正文。
- 每篇 `.body.md`：用于结构核对的中文主体。
- 每篇 `.source.md`：保留的完整英文正文及来源编码。
- `license.json`：公开转载及翻译条款的来源和核验日期。

每篇文章醒目标明 Icy Veins、原作者、专精主页及十个章节原文链接。转载和翻译依据为 [Icy Veins 官方 FAQ](https://www.icy-veins.com/faq) 的非商业使用条款。

## 来源差异与校订范围

原文有 7 处物品变体参数超过当前引用编码范围或格式异常。保留基础物品引用，并将原始参数、出现位置和原文地址完整记录在 `source_payload.source_parameter_warnings` 及引用来源信息中，没有猜改奖励编号。

部分历史技能或套装效果标识尚无权威中文名称，随文译名仅用于阅读兜底。原文的空名失效引用 `spell:280749` 也保留其来源编号。宏中的示例占位符、未能按编号核验的技能名和 Lua 保持原样，相关说明保存在 `source_payload.macro_localization_notes`；已核验技能名按中文替换，宏指令和条件不交给翻译服务改写。

全文经过机器翻译及结构、引用、数字差异核对，并非全部句子的人工专业审校。图片和视频地址沿用来源可访问地址，未打包第三方媒体文件。

本次交付包含初始化数据、生成脚本及验证结果。生产数据库导入和部署仍由线上执行。
