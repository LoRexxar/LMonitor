# Icy 正文格式适配

> 前期工作记录：本次完整中文攻略请使用 [完整攻略导入说明](icy-完整攻略导入说明-20261022.md) 中的 `icy-full-initial-20261022.zip`。本文件所述导读包或结构样例不作为最终交付。

本轮实现先解决正文与组件的转换协议。三类真实页面仅用于检查 DOM；验证前将第三方攻略叙述替换为原创占位文本，没有生成这些页面的全文译本。上一版导读 ZIP 仍是导读，不应当作完整攻略包使用。

## 当前映射

| 来源结构 | 当前格式 | 保留的数据 |
| --- | --- | --- |
| 专精的多个章节文件 | 单篇 Markdown | 章节顺序、各章地址及输入摘要 |
| 页面标题与小标题 | 二级章节及后续层级标题 | 原有标题文本与层级 |
| 天赋导出组件 | `talents` 扩展组件 | 游戏构筑字符串与方案标题 |
| 网站天赋计算器 | 代码块 | 网站压缩编码，不误认为游戏导入串 |
| 默认隐藏的方案 | 连续的独立章节 | 所有方案及其解释正文 |
| 循环列表与分支 | 嵌套有序列表 | 步骤顺序、嵌套动作及天赋条件 |
| 装备网格 | HTML 表格 | 部位、物品、变体与获取说明 |
| 技能、装备引用 | 当前双中括号引用 | 编号、奖励参数、等级、来源分支及原始参数 |
| 表格 | 清洗后的 HTML 表格 | 合并行列与单元格内容 |
| 折叠说明与分组 | `details` 组件 | 标题与完整正文 |
| 图片与相对链接 | Markdown 图片与绝对链接 | 图片地址、替代文本与链接目标 |
| 宏、代码和构筑数据 | 代码块或组件配置 | 原始代码，不列入叙述翻译字段 |

转换器不执行来源脚本。脚本生成的组件缺少静态编码、未知引用、条件名称缺失、物品变体超出既有协议时，会输出结构问题，等待补全。不会自动猜测错误奖励编号，也不会用默认显示方案覆盖其他方案。

## 本地文件输入

使用单专精清单描述需要合并的章节。格式参考 `icy-format-example/manifest.json`，该目录的三个 HTML 均为原创结构测试样例。样例中的动作、构筑字符串与装备编号不代表实际游戏建议。

清单字段为：

- `spec_id`：全站暴雪专精编号。
- `game_version`：来源页面版本，例如 `12.1.5`。
- `author`：可选作者信息。
- `chapters`：按顺序排列的章节列表；每项含 `title`、`source_url`、`file`。

`file` 使用相对于清单目录的本地 HTML 路径。章节来源必须属于所选专精。将获授权的正文文件填入该目录后，可以通过以下命令准备格式：

```console
python manage.py prepare_icy_class_guide --input-manifest 正文目录/manifest.json --output-dir 新输出目录
```

命令读取本地文件，输出新目录，不写入数据库：

- `source.md`：已合并、已转换的完整来源正文，语言与输入文件相同。
- `conversion.json`：职业专精、标签、章节来源、正文块、来源引用、结构问题及待翻译文本节点。

待翻译字段由 `id`、`field`、`node_index` 和 `source` 定位，跳过代码节点。翻译时应只替换对应文本节点；链接、HTML 属性、天赋代码与组件 JSON 保持原样。完成翻译后仍需进行内容和结构核对，再使用当前草稿包协议生成初始化 ZIP。本命令本身不生成或导入最终发布包。

## 验证结果

新增九项原创样例测试通过，覆盖天赋方案、计算器编码、隐藏分支、条件循环、装备变体、表格合并、图片、宏、链接、引用合并、异常报告和命令输出。

实际执行原创三章节样例，转换出 49 个待翻译文本节点，结构问题为零。该结果用于验证格式，不代表真实攻略内容已翻译。

三类真实 DOM 去正文验证结果见 `icy-structure-check-20261022.json`：

- 天赋页：5 个游戏天赋组件，37 个唯一引用，结构问题为零。
- 循环页：49 个唯一引用，66 处条件标记，结构问题为零。
- 装备页：79 个唯一引用；同一条奖励编号超出协议范围的引用出现两次，另有一条货币引用不在现有三类引用协议中。这三项已显式记录，不能视为完整验收通过。

复验命令：

```console
python manage.py test botend.tests.test_class_guide_icy --settings=LMonitor.settings_test_sqlite --noinput
python scripts/check_icy_guide_structure.py --output 新的结构核对报告.json
```

结构核对脚本只保存统计与问题，不保存网页攻略正文。若网站组件结构变化，报告和转换规则仍需重新核对。
