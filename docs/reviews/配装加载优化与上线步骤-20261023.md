# 配装加载优化与上线步骤

## 问题与修复

页面原来依次等待初始化资料、已有配装刷新、方案库解码，之后才绘制槽位并请求装备目录。即使本地已有完整配装，刷新接口慢也会让左侧与中间长时间空白。

现在在本地配装恢复后立即绘制槽位，目录加载与中央资料刷新并行执行。职业、专精切换使用相同流程。刷新完成时核对请求序号与发起时的完整状态，用户已经换装、切换专精、锁定或清空时丢弃迟到结果；刷新失败保留原配装。方案库恢复完成后才开放保存操作，避免初始化期间覆盖已保存方案。

刷新后端只查询实际引用的物品与变体键，同一物品通过预取只加载一次。已属于当前赛季批次的变体不再重复查询当前版本；跨批次仍严格匹配物品、变体键、装等和分支，保留原有不替换用户选择的约定。

公开刷新接口复用装备目录的元数据白名单，剔除模拟激活资料和原始采集证据。物品身份、装等、属性、已解析制造属性、特效、来源、宝石、附魔、美化、插槽和制造参数均保留。中央服务与数据库仍使用完整资料计算，不裁剪数据库字段。用户提交并通过校验的历史完整快照原样恢复，已保存的原始分享字符串不重写。

配装页不再请求外部 Tailwind 运行时脚本，改用随版本发布的本地基础 CSS。其他页面不在本轮范围内。

## 验证证据

2026 年 10 月 23 日采集线上公开狂暴战头部目录及一件头部装备的只读刷新响应。按相同 JSON 编码，响应从 89,832 字节变为 2,969 字节，减少 96.7%。主要移除的是 `simc_effect_activation_by_build`。这是一个真实样本，不代表所有配装都按同比例减少。

在隔离 Edge 浏览器中，使用真实页面模板、脚本和上述线上样本，将刷新接口延迟固定为 2.5 秒：

| 项目 | 基线脚本 | 优化脚本 |
| --- | ---: | ---: |
| 左侧槽位可见 | 3,259 毫秒 | 405 毫秒 |
| 装备目录可见 | 3,275 毫秒 | 631 毫秒 |

两组使用相同本地样式，单独验证解除刷新阻塞的收益，不将外部 CDN 波动算入收益。优化组在刷新返回前已能展示目录。两组真实属性面板完全一致，力量 189、急速 60、精通 141；换装成功，页面脚本异常为零。该对比不是优化代码部署后的生产数据库耗时，也不包含用户完整浏览器私有配装的全量验收。

- 后端 121 个测试通过，包含真实 ORM、历史分享、制造属性及强化恢复、元数据裁剪、目录预取和只读接口验证。
- 前端 29 个测试通过，包含属性、宝石、锁定、分享往返、慢响应期间显示本地配装、迟到响应隔离。
- ORM 范围测试添加 30 个同物品未选变体后，刷新仍只加载四个实际引用变体，同一物品只加载一次。
- 历史完整快照的原样恢复测试保持通过；没有通过修改测试预期取消这一保证。
- 浏览器测试使用隔离配置与拦截响应；不写线上账号配装，不运行生产迁移，不进行压力测试。

本地证据位于 `tmp/gear-startup-20261023/`，测试日志为 `tmp/gear-startup-final-20261023.log`、`tmp/gear-startup-js-final-20261023.log` 与 `tmp/gear-startup-browser-final-20261023.log`，不纳入版本库。

复现浏览器验证：

```powershell

python botend/tests/js/gear-startup.browser.py --capture
```

脚本需要本地 Django、Playwright 与 Edge，比较基线提交 `bb08e739` 的启动脚本和当前工作树。它不连接生产数据库。

## 上线步骤

使用线上应用既有虚拟环境与配置执行：

```sh
git pull --ff-only origin master
python manage.py check
python manage.py collectstatic --noinput
```

随后按现有部署方式重启 Web 应用进程。本次没有新增数据库迁移，无需重新采集 WCL、重建聚合或清理装备目录。新 JS 地址带版本号 `20261023_startup`，新增本地样式 `portal/css/gear_builder_base.css`；静态资源必须与模板一起部署。

验收时用已有配装打开页面，确认本地槽位先显示、候选装备可操作；等待刷新完成后核对属性、宝石、附魔、制造绿字与锁定状态，再测试换装及旧分享导入。网络面板应没有 `cdn.tailwindcss.com` 请求，普通引用刷新结果不再包含 `simc_effect_activation_by_build`。历史完整快照校验响应仍可能包含用户原来携带的字段，这是原样恢复约定。

## 本地基础样式维护

基础样式已编译入库，线上不需要安装 Node 或运行编译。后续修改模板中的工具类时，在开发环境重新生成并一并提交：

```powershell
npx --yes tailwindcss@3.4.17 -i scripts/gear-builder-base.css -o static/portal/css/gear_builder_base.css --content 'templates/portal/gear_builder.html,templates/portal/_header.html,templates/shared/_character_shortcuts.html,static/portal/js/gear_builder.js,static/portal/js/portal-theme.js,static/shared/js/wow-item-tooltip.js' --minify
```
