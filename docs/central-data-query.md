# 中央装备与天赋查询

后台「运行维护 → 装备与天赋查询」提供只读聚合页面，地址为 `/dashboard/?section=central-data`。两个页签共用搜索、正式服／测试服选择、分页与详情弹窗；筛选条件保留在地址中，刷新后仍可继续查看。

## 权限

独立权限为 `database.central-data`（装备与天赋查询）。超级管理员自动拥有；其他用户在后台用户组中勾选该权限后访问。仅授予此权限不需要开放数据库表编辑权限。页面与接口分别校验权限，响应不缓存。

## 装备页签

- 直接读取中央物品与赛季变体，按物品编号聚合；每个赛季仅纳入其当前已发布目录批次。未进入任何当前目录的孤立采集记录、旧目录及待发布批次不在此页面范围内。
- 可组合筛选赛季、类型、部位、实际品质、升级轨道、装等范围及中文名称完整度；支持中文名、英文名、物品编号和模拟器标识搜索。
- 多个变体只占一行。数量、品质集合及装等范围均按当前筛选计算；品质优先使用副本难度变体的实际品质，再读取所属分支的中央品质。
- 详情展示中文优先的装备说明、公共特效机制、各变体的属性和特效、掉落来源及采集信息。公共机制没有当前变体数值时明确显示待确认，不使用其他装等数值冒充。
- 图标名称来自中央资料，装备图片共用前台的统一图标服务，天赋使用 Wowhead 图标服务；详情明确展示图标名称与来源。未映射的数字文件编号不拼成图片地址，来源已确认的数字图标名仍正常显示。无图标或图片加载失败不会显示破损图片。

## 天赋页签

- 只读取所选分支当前活动的结构节点；退役节点与纯名称补充记录不作为独立天赋重复列出。
- 按明确关联的展示技能／技能编号合并，未关联技能的节点独立展示。英雄树入口编号不能冒充技能编号。
- 支持职业、专精、天赋树、最终描述合成状态筛选，以及名称、描述、技能编号、节点编号、天赋编号搜索。
- 描述共用中央技能的最终展示字段；关联节点详情按职业、专精、节点读取差异，展示公共描述及适用差异，不重新解析原始模板。构建号只用于说明来源，不作为查询门槛。
- 正式服与测试服单独读取，缺失分支返回空列表，不借用另一个分支的中文。已有中文优先展示，缺失描述如实提示待补齐。

## 数据与接口

此页面没有新增表、物化聚合记录或中间文件，不需要新增迁移。查询不写入资料、不触发采集、不重新合成。部署前需按已有中央装备、天赋文档完成对应字段迁移与存量合并。

接口为 `GET /api/dashboard/central-data/`。`resource=items|talents` 选择资料，`branch=retail|ptr` 选择分支，`q` 为关键词。`page` 与 `page_size` 控制分页，每页最多 100 条；添加 `id` 获取详情，天赋详情另用 `identity_kind=spell|node` 区分编号空间。详情保留列表筛选条件，其关联列表也分页。

装备筛选参数：`season`、`variant_type`、`slot`、`quality`、`upgrade_track`、`min_level`、`max_level`、`language=translated|missing`。

天赋筛选参数：`class_name`、`spec_name`、`tree_type`、`status=ready|partial|unbuilt`。

聚合、条件和分页先在数据库执行，随后只为当页资料批量补充展示内容；列表不逐行读取详情。查询支持只读请求，写入方法返回不支持。
