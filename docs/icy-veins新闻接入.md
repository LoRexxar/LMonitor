# Icy Veins 新闻接入

## 接入范围

- 优先采集入口：https://wp-prod.icy-veins.com/custom-rss/?category=wow 。失败时回退 https://www.icy-veins.com/wow/ ，仅处理本站 `/wow/news/单篇标题/` 新闻链接，排除攻略、其他游戏和外站链接。
- 复用现有 `PortalPostMonitor` 调度，在其他门户来源采集完成后执行；不新增任务配置或数据库迁移。
- 来源标识为 `icy_veins`，显示名称为 Icy Veins。首页增加独立来源卡片，复用日期筛选、站内阅读及中文翻译。
- 与 Wowhead 一样使用 `category=news`，通过标题前缀保存版本标签。RSS 的明确分类 `WoW`、`WoW Classic`、`WoW Forever` 分别映射正式服、怀旧服、无限；多分类保留为 `[正式服/怀旧服/无限]`。网页回退只使用明确的文章分类元数据，缺失时标 `[魔兽世界]`，不根据标题关键词推断版本。已有条目补标签时保留原题、译文和正文。
- 最新新闻接口：`/portal/api/icy-veins/latest/`，支持 `days` 或 `start_date`、`end_date`，按北京时间自然日读取快照。
- 新闻历史接口支持 `source=icy_veins`；详情继续复用已有文章接口。

## 采集和失败处理

每轮最多读取分类 RSS 的 100 条记录；网页回退最多读取 20 篇。统一域名、尾斜杠并移除查询参数，按网址哈希复用已有记录。已有正文和发布日期时不重复抓取详情，不覆盖已有翻译。

RSS 中的作者、带时区的发布日期和 `content:encoded` 完整正文直接进入现有文章链路，一次请求即可提供多篇新闻。`description` 只作为摘要，不能冒充正文；缺少正文时才补抓详情。兼容原始 XML 与 Chromium XML 查看器嵌入的原始 `rss` 节点，拒绝实体声明、异常日期和其他游戏链接。

详情使用正文容器，保留标题、列表和图片，通过现有文章渲染链路展示。发布时间读取文章元信息、结构化数据或带时区的绝对时间，不以抓取时间替代。无法取得正文或有效发布时间的新文章暂不入库，下轮重试。

普通请求失败或返回无效页面时，仅在现有请求器已启用浏览器的情况下使用其浏览器回退能力。浏览器返回后，最多等待 45 秒让实际内容出现，期间复用同一页面、不重新导航、不点击验证码。验证码和站点验证页不会作为新闻保存。单篇异常后继续处理其他文章；整轮发生失败时返回失败状态并记录日志，已有文章不清空。租约丢失时中止执行。

每轮最多尝试翻译 3 篇，失败也消耗本轮预算；原文先保存。`PortalArticleTranslateMonitor` 同时纳入此来源，按已有补偿机制重试未完成的翻译。

与 Wowhead 调用同一 `ArticleTranslationService.translate_article_fields`，使用同一翻译引擎选择和魔兽术语表，分别保存 `title_cn`、`content_cn`、`content_blocks_cn`。确定的中文版本标签不交给模型翻译，翻译后由程序恢复；已完成翻译不重复请求。集成测试使用真实翻译服务及测试数据库，仅模拟翻译引擎响应，覆盖首次采集翻译、服务不可用后补翻译、标签修复和接口快照传递；不代表真实模型服务或生产采集已验证。
