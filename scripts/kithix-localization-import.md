# 基希克斯破封中文增量更新

适用于线上已通过 `import_ptr_journal_gear_overlay` 导入基希克斯、但仍显示英文的情况。更新命令离线读取仓库自带制品，不要求线上访问 Wago，也不上传图标、不重建整个装备目录。

## 线上执行

先将本次代码、模板以及 `botend/data/kithix_localization_12_1_5.json` 一起部署到服务器，使用现有线上 Python 环境和数据库配置，在项目目录执行：

```powershell
# 只预览，不修改数据库
python manage.py update_kithix_localization

# 备份后实际更新
python manage.py update_kithix_localization --apply
```

命令适用于 Windows 和 Linux；如果线上平时指定 `--settings`，本命令沿用同一个线上设置。不要使用测试设置连接线上数据。本次没有新增数据库迁移。

更新后重载应用进程并刷新页面，使职业聚合读取逻辑和模板变更生效。无需重新跑全职业聚合，已有聚合 JSON 的装备展示会在读取时使用当前中文目录，原始样本、人数、占比及装等不变。

## 更新范围

1. 配装模拟器：10 件装备的中文名称、说明、掉落首领和全部现存活动变体的中文特效。原始制品包含 180 个变体，命令处理线上实际存在的活动变体。
2. 冒险手册：副本背景、首领介绍、技能章节、职责提示、掉落名称和说明。保留原有首领、章节结构、难度和掉落关系。
3. 职业聚合统计：新生成数据和旧聚合文件都会刷新相关装备的中文名称与提示框；不会改写历史统计文件或角色原始装备。
4. 冒险手册归属：加入当前活动赛季的“本赛季”目录，副本卡片、详情及物品提示框不再显示 PTR 标签。内部仍保存真实 PTR 来源和构建编号，不把它伪装成正式服数据。
5. 三个非装备掉落：补充中文基础资料，避免提示框再回退到外站英文或请求失败。

## 数据来源与保留边界

中文直接来自 Wago 的 `12.1.5.70077 / zhCN` 客户端数据，制品保存原始表及来源链接。装备现有属性、装等、插槽、升级轨道、特效数值和数值构建全部保留；特效通过原始英文模板提取已验证数值，再按相同变量填入官方中文模板。变量不一致、原文无法匹配或缺少中文时，整次导入拒绝写入。

**两件装备发生过部位调整，需与语言更新区分：** `281235` 的新版中文为“虚空编织者护腿”，旧目录部位为胸部；`281236` 的新版中文为“具象恐惧护胸”，旧目录部位为腿部。此命令会输出提示，但不会用新版本的部分字段覆盖旧版装备事实。因此，旧目录上这两件装备会暂时存在中文名称与原部位不一致；完整升级装备数据需要另行同步同构建的部位、属性、图标及特效，不能仅凭名称交换部位。

手册技能文本按中文制品解析，运行时缩放伤害继续标为动态数值。总掉落数为 13，具体难度可能只展示其中一部分。物品提示框仍使用原数值构建的参考装等，不等同于所选难度的初始掉落装等。

## 备份、失败与重复执行

- 默认备份保存在项目 `media/import-backups/kithix-zh-时间戳.json`，包含旧手册发布 ID、受影响物品及变体的修改前字段。可以通过 `--backup 路径` 指定新文件；已有文件不会被覆盖。
- 旧冒险手册发布完整保留，更新生成新发布并原子切换。若只缺物品中文，则不额外生成相同手册发布。
- 所有数据库写入在同一事务中完成，任何一步失败都会回滚。备份文件保留，方便检查。
- 再次执行会检查实际数据，全部一致时显示“无需重复更新”，不新增发布或备份；若后来被其他导入覆盖，可重新执行恢复中文。
- 同步任务持有手册同步锁时拒绝执行，避免相互覆盖。本赛季展示归属会随下一次手册同步保留，仅在原活动赛季内生效。
- 备份不是自动回滚命令。人工恢复时应先核对赛季、批次和当前发布，恢复备份中的旧字段；不要直接恢复整库，以免覆盖其他更新。

## 重新生成来源制品

通常不需要执行。需要重新获取同一固定构建时：

```powershell
python scripts/build_kithix_localization.py
```

下载结果缓存到项目 `.cache/kithix-localization/12.1.5.70077`，中断后可继续。脚本只下载资料并生成制品，不连接数据库。更换构建需要重新审查中文变量与原数值模板的兼容性。
